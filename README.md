# AV2 - Lógica de Programação

Projeto desenvolvido como atividade avaliativa da disciplina de Lógica de Programação.

## Descrição

O algoritmo simula um sistema simples de atendimento de pedidos em uma lanchonete, permitindo:

* Cadastro do nome do cliente;
* Registro de múltiplos itens do pedido;
* Informar quantidade e valor de cada item;
* Cálculo do valor total dos produtos;
* Aplicação de desconto;
* Cálculo da taxa de entrega;
* Exibição de um resumo final do pedido.

## Tecnologias

* Portugol Studio
* Conceitos de Lógica de Programação

## Conceitos Utilizados

* Variáveis
* Vetores
* Estruturas de decisão (`se`)
* Estruturas de repetição (`para`)
* Operadores aritméticos
* Entrada e saída de dados
